# Technical Event Visual Brief Template

Use this template before creating visual materials for a technical event. Fill only what is known; mark unknown items as `TBD`.

## 1. Basic Event Info

**Event Name**  
`[Fill in the official event name]`  
Tip: Use the final public-facing name. Keep it under 20 Chinese characters or 8 English words if possible.

**Event Type**  
`[Forum / Exhibition / Hackathon / Demo Day / Workshop / Product Launch / Community Meetup / Other]`  
Tip: This decides the visual tone and asset structure.

**Date & Time**  
`[Fill in date, time range, timezone if needed]`  
Tip: Use the exact public-facing format.

**Venue / Online Link**  
`[Fill in venue, room, booth number, livestream channel, or online link]`  
Tip: Include the minimum info people need to arrive or join.

**Hosts / Co-hosts / Partners**  
`[Fill in official organizer names]`  
Tip: Confirm logo order and naming before design starts.

## 2. Objective & Audience

**Primary Goal**  
`[What should this visual campaign achieve?]`  
Tip: One sentence. Example goals: drive registration, invite media, attract developers, announce agenda, promote livestream.

**Target Audience**  
`[Researchers / Developers / Media / Investors / Partners / Students / Customers / Community members / Other]`  
Tip: Pick 1-3 primary audiences. Do not target everyone equally.

**Audience Motivation**  
`[Why would they care about this event?]`  
Tip: One sentence. Focus on learning value, networking value, business value, or community value.

## 3. Core Message

**One-line Hook**  
`[The strongest sentence that should attract attention]`  
Tip: 15-30 Chinese characters or one short English sentence.

**Event Positioning**  
`[What kind of event is this, and why is it different?]`  
Tip: 1-2 sentences. Avoid generic words such as "high-end", "cutting-edge", or "empowering" unless supported by specifics.

**Technical Keywords**  
`[List 5-10 technical keywords]`  
Tip: Use real terms that the target audience recognizes.

**Brand Message / Slogan**  
`[Fill in brand statement if any]`  
Tip: Keep it short enough to appear on a poster or cover.

## 4. Main Visual State

**Do We Have an Approved Main Visual?**  
`[Yes / No]`  
Tip: If yes, attach the image or Figma link.

**Reference Images**  
`[Attach links or filenames]`  
Tip: Add 2-5 references if there is no approved main visual.

**Brand Assets**  
`[Logo / Product image / Speaker photos / Venue photo / Previous posters / Brand guideline / None]`  
Tip: List what is available and what is missing.

**Visual Tone Preference**  
`[Research / Industrial / Premium / Community / Playful / Academic / Minimal / Other]`  
Tip: Choose 2-3 words maximum.

**Visual Restrictions**  
`[What should not appear?]`  
Tip: Mention forbidden colors, image styles, logos, robot forms, sensitive wording, or competitor references.

## 5. Content Structure

**Must-show Information**  
`[List information that must appear on the main poster]`  
Tip: Keep this short. Too much information should move to long image or agenda image.

**Nice-to-have Information**  
`[List optional information]`  
Tip: These can appear in long images, captions, or secondary slides.

**CTA / Registration Info**  
`[QR code / Link / Contact person / Deadline / Ticket info]`  
Tip: Include deadline and eligibility rules if relevant.

**Agenda Summary**  
`[Paste structured agenda or attach file]`  
Tip: Include time, session type, speaker name, and topic.

**Speaker Info**  
`[Name / Title / Institution / Talk topic / Technical tags / Headshot]`  
Tip: Keep each speaker description under 50 Chinese characters for posters.

## 6. Required Assets

**Output Channels**  
`[WeChat Official Account / Xiaohongshu / Community Group / Media / Figma / Print / Booth screen / Livestream / Other]`  
Tip: Different channels need different ratios and text density.

**Size / Ratio Requirements**  
`[Fill in exact sizes if known]`  
Tip: If unknown, state the channel and let the designer/AI choose safe ratios.

## 7. Review & Delivery

**Reviewer / Approver**  
`[Name and role]`  
Tip: Identify who can approve brand, content, and final export.

**Deadline**  
`[First draft deadline / final export deadline]`  
Tip: Separate draft deadline from final delivery.

**Editable Source Required?**  
`[Figma / SVG / PPT / PSD / No editable source needed]`  
Tip: Figma is recommended for collaborative review.

**Final Export Format**  
`[PNG / JPG / PDF / SVG / Other]`  
Tip: Use PNG for most digital posters and JPG for compressed social posting when needed.

**Notes / Risks**  
`[Anything the designer or AI should watch out for]`  
Tip: Mention uncertain agenda, unconfirmed speakers, logo approval, sponsor order, or ticket rules.
