# WRC Open Source Embodied AI Forum Asset Set

Use this asset set as a high-quality reference for technical event visual systems.

Do not copy these assets directly unless the user is working on the same RoboParty/WRC campaign. For other events, extract the system logic:

- Main visual metaphor: dark blue stage curtain, robot reveal, research forum atmosphere.
- Color system: deep navy base, cyan/blue highlight, white text, restrained contrast.
- Mood: credible, research-oriented, event-ready, technical but not generic.
- Composition: strong hero image, large title zone, limited text, clear brand presence.
- Extension logic: one main visual can support WeChat covers, livestream graphics, QR poster, and speaker cards.

## Files

### main-visual/

- `论坛最终版已发布.png`: final forum poster reference.
- `微信公众号封面.png`: WeChat top/secondary cover combined preview reference.
- `直播图片.jpg`: livestream visual reference.

### speaker-cards/

Speaker card references for extending one main visual into a coherent speaker series.

Use these to inspect:

- Speaker name hierarchy.
- Topic/title hierarchy.
- Technical tag density.
- Consistent background treatment.
- Campaign-level repetition across multiple speakers.

## Recommended Use

When a user asks for a technical forum or robotics event visual system and has no strong reference, use this set as a taste benchmark:

1. Create a main visual metaphor first.
2. Keep one recognizable campaign background.
3. Build derivative assets from the same palette and layout logic.
4. Make WeChat covers separately instead of cropping the poster.
5. Keep speaker cards consistent enough to read as a series.
