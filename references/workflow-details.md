# Workflow Details

## Main Visual Decision Tree

Ask these questions first:

1. Is there an approved main visual?
2. If not, are there strong reference images?
3. If not, are there brand assets and event keywords?
4. What channel is the most important: WeChat, Xiaohongshu, community group, media, or print?

Decision:

- Approved main visual: extend, do not reinvent.
- References only: synthesize 2-3 directions and ask for a direction choice when stakes are high.
- No reference: create visual strategy first, then generate a main visual.

## Designer + AI + Figma Workflow

Best-practice team workflow:

1. Designer creates or approves the main visual.
2. Planner structures all event information.
3. AI produces derivative materials quickly.
4. Figma is used for collaboration and final adjustment.
5. Operator exports per-channel assets.

Figma adjustment checklist:

- Correct logo placement.
- Correct font weight and hierarchy.
- Check Chinese/English line breaks.
- Check text does not sit on complex image areas.
- Check image crop for all aspect ratios.
- Check mobile preview readability.
- Check all derivative assets still look like one campaign.

## WeChat Cover Pack Ratios

Use platform-current specs if provided by the user. If no current spec is provided, use safe working canvases:

- Top story cover: wide horizontal, usually 2.35:1 style.
- Secondary story cover: square or near-square.
- Combined upload preview: place top cover on the left and secondary cover on the right, matching the operator's upload workflow.

Principle:

- Top cover is the hook and identity.
- Secondary cover is recognition and simplicity.
- The combined preview is a working asset, not a public communication asset.

## Technical Event Visual Taste Rules

Good:

- Strong metaphor.
- Real product or credible abstraction.
- Restrained color palette.
- Clear reading zones.
- Strong title hierarchy.
- Mobile-first text scale.
- Visual continuity across assets.

Bad:

- Full agenda pasted into one poster.
- Generic blue-purple gradient.
- Random circuit-board lines.
- AI-looking humanoid robots with no relation to the event.
- Too many logos competing with the title.
- Tiny speaker descriptions.
- Overuse of glow effects.

## Default Deliverable Set

For a full campaign:

1. Main poster
2. Long image
3. Agenda image
4. Speaker cards
5. Media/community invite image
6. WeChat cover pack
7. Xiaohongshu carousel cover
8. Booth visit image
9. Recap template

For a lightweight campaign:

1. Main poster
2. Agenda image
3. WeChat cover pack
4. Community invite copy
